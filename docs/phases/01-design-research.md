# Phase 1 — Design Research

## Goal

Research a small set of leading developer portals and extract reusable design/UX patterns for this project.

## Primary references

- Twilio
- Vonage
- Stripe
- GitHub
- Cloudflare
- Shopify

Give extra weight to Twilio and Vonage.

## Preferred skills

Primary:
- UI/UX Pro Max

Use research to create the design system, not to copy one site.

## Required analysis

Study:
- information architecture
- global navigation
- sidebar behavior
- endpoint-page layout
- search
- code-block UX
- authentication presentation
- request/response presentation
- method badges
- parameter tables
- webhooks/events presentation
- versioning
- changelog
- responsive behavior
- dark/light mode
- typography
- spacing
- motion
- API testing/Playground patterns

## Deliverables

Create/update:
- `design-system/RESEARCH.md`
- `design-system/MASTER.md`

The research summary must include:
- 10 patterns worth adopting
- 5 patterns to avoid
- proposed navigation
- proposed endpoint layout
- proposed Playground layout
- proposed design-system direction

## Design target

80% clean professional developer portal
20% subtle futuristic character

Avoid generic AI-site styling.

## Model

Default:
Sonnet 5

## Gate

STOP after research and design recommendation.

Do not:
- implement the full portal
- crawl Proxy API docs
- build the Playground
- begin Open API work

Wait for explicit user approval.
