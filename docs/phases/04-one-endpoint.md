# Phase 4 — One Real Proxy API Endpoint

## Goal

Implement exactly one suitable real Proxy API endpoint as the vertical-slice prototype.

Prefer a read-only endpoint when available.

## Required page content

- title
- description
- HTTP method
- path
- authentication
- parameters
- required/optional indicators
- request example
- response example
- errors
- notes
- related information
- Try It entry point

## Required behavior

Use real documented evidence.
Do not use fake API behavior for the Live path.

## Model

Sonnet 5 default.
Escalate to Opus 5.5 for unresolved high-consequence API interpretation.

## Completion gate

Required:
- one endpoint represented accurately
- reusable components used
- no unnecessary Proxy-specific component architecture
- tests pass for implemented scope

DO NOT:
- implement another endpoint
- begin full Proxy API migration
- begin Open API work

STOP and request user approval before scope expansion.
