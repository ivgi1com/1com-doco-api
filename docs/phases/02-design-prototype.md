# Phase 2 — Design Prototype

## Goal

Build a local visual prototype of the portal shell after the user approves Phase 1.

## Preferred skills

- Anthropic `frontend-design`
- Vercel `react-best-practices`
- Vercel `web-design-guidelines`
- Microsoft Playwright

## Scope

Prototype:
- header
- sidebar
- navigation
- content area
- endpoint-page visual concept
- code blocks
- method badges
- parameter table concept
- Playground visual concept
- responsive layout

Do not implement the complete API.

## Model

Sonnet 5 for implementation, testing and Playwright validation.
Opus 5.5 only if an architectural question surfaces mid-phase.

## Validation

Run:
- UI audit
- React/Next.js best-practice review
- Playwright desktop/mobile visual checks

## Gate

STOP for user approval.

Do not begin API migration before approval.
